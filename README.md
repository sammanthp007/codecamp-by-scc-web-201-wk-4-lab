# FocusFlow — Week 4 Starter (Web-201)

This repo is intentionally split into:
- UI components and feature panels that already render
- Hook “slots” that students will implement during the Week 4 Lab

## Run
```bash
npm install
npm run dev
```

## What students implement in the Lab

* `src/hooks/useLocalStorageState.ts`
* `src/hooks/useInterval.ts`
* `src/features/tasks/useTasks.ts`
* `src/features/timer/usePomodoro.ts`

## Goal

By the end of Week 4, this becomes a real Pomodoro + Tasks app with persistence.
